# Contributing

1. Open an issue before substantial changes.
2. Create a branch from `dev`; do not open the first change directly against `main`.
3. Keep source changes focused and add or update a test when behavior changes.
4. Run `python -m unittest discover -s tests -v` and, when available, `bash scripts/test-hdl.sh`.
5. Do not commit generated Vivado output, proprietary course collateral, credentials, personal data, or absolute local paths.
6. State the provenance and license of every imported third-party file.

By contributing, you agree that your contributions may be released under this repository's MIT License.
